# 2026-10-23 房间流程与界面整理

## 修复

- 观战者接任房主后，手机底部与桌面操作面板都保留下一题、查看结果及作画失败重试入口。观众身份和本局计分规则保持原有约束。
- 准备下一局保留手选 AI 和纯真人名单。记录准备名单所属账号，只有所属账号与现房主不同才加载新房主默认配置；新房主已手动修改的名单也会保留。客户端进入准备页时采用服务端名单。
- 查看聊天历史时，原位置的 AI 等待占位成功、失败或取消后会出现“有新回应”提示，不强制滚动。
- 手机底部高度由现有 ResizeObserver 测量。移除了 body 上覆盖根节点测量值的固定 CSS 变量，画布与提示面板现在使用实际工具栏高度。

## 界面调整

角色资源提示改为折叠详情。Live2D 加载失败显示名称首字母和独立重试按钮，按钮带具体角色的可访问名称。窄桌面选手网格调整为两列；手机抽屉中的作答输入框独占一行，提交保持主操作，跳过保持次操作。聊天正文提高到 14px，等待消息增加状态点，辅助说明使用对比度更高的共享文字色，补充统一键盘焦点轮廓。

## 验证与限制

针对房间接续、配置归属、聊天状态、选手展示和真实 HTTP 模拟接口的 41 项回归全部通过。JavaScript 语法和 Git 空白检查完成；未调用付费模型。

浏览器自动安全策略拒绝访问当前本地预览 URL。本次仅参考 2026-10-21 同版本截图与源码，没有改用其他浏览器或间接控制方式绕过限制。因此本轮新增布局没有进行实时浏览器、手机或 Live2D 渲染验收，旧截图不作为新布局的验收证据。

设计检测的低对比度辅助文字已调整。另四条“同排卡片的边框与大阴影”提示实际对应 settingsDialog、relayPictureDialog、roomDialog 和 confirmDialog 四个独立原生弹窗；为该规则添加仅限 public/index.html 的忽略并记录理由，没有关闭其他规则。
